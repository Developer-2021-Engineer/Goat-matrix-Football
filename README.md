# ⚽ THE GOAT MATRIX

> **Quantitative Football Analytics & The Search for Perfection**

An interactive, single-file web analytics platform that models and ranks the top 50 football legends in history using 100% real-world historical match data (Opta, StatsBomb, FBref archives) with **zero video game / EA Sports bias**.

## 🌟 Key Features
- **Theoretical Perfection Anchor $(100, 100)$:** Evaluates players using Euclidean distance $D = \sqrt{(100 - X)^2 + (100 - Y)^2}$ to measure proximity to absolute theoretical perfection.
- **Dual Model Views:** Seamlessly switch between Overall Career GOAT rankings and Single Best Peak Season Zenith models.
- **Interactive Canvas Engine:** Custom HTML5 Canvas scatter plot with symmetrical crosshair axes ($X-X'$ and $Y-Y'$), distance orbit rings, smooth mouse-wheel zooming, and drag-panning.
- **Google-Style Auto-Suggest Search:** Glassmorphic search dropdown that dynamically highlights, centers, and inspects legends in real time.
- **Head-to-Head Duel Comparison:** Side-by-side player match-ups with overlaid 5-axis Chart.js radar charts.
- **Master Leaderboard:** Fully sortable 50-player ranking table filtered by role (Attacker, Midfielder, Defender, Goalkeeper) and era.

## 🛠️ Built With
